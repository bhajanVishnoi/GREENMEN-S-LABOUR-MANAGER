# GreenMen's Labour Manager — Android starter

This is the first offline-first Android Studio starter for the requested labour management app.

Included:
- Dashboard
- Add labour (name, mobile, wage/day, village)
- Local/offline labour storage
- Attendance record
- Wage total calculation
- Basic report screen
- Camera launch for the Face Attendance flow

Important: the current starter opens the camera but does **not** claim to perform automatic face identification. A production face-recognition build needs an on-device face recognition model and secure storage of face templates. The next implementation should add enrollment + matching, labour-wise attendance, advance/payment ledger, PDF/Excel export, PIN lock, and backup.

Open the folder in Android Studio and build the app with an Android SDK installed.
